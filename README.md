## Запуск

1. Установите Node.js 20 или новее.
2. Откройте папку репозитория в VS Code.
3. В терминале запустите `npm start` либо `npm.cmd start` (зависимости устанавливать не требуется).
4. Откройте `http://localhost:3044` в браузере.
5. Исследуйте запросы во вкладке **DevTools → Network → Fetch/XHR**.

Не открывайте `index.html` через `file://` и не запускайте Live Server: HTTP API обслуживает `server.js`.

## API

- `GET /api/tickets` → `{ "items": [...], "total": 3 }`
- `POST /api/tickets` → JSON `{ "customer": "...", "problem": "..." }` → HTTP 201 и объект новой заявки
- Некорректные поля → HTTP 422 с `error`.

## Проверка

GET показывает три исходные записи; POST создаёт четвёртую; пустое обращение не отправляется; после POST список обновляется.
